How this test works / privacy

This page makes a direct read-only request from your browser to Vinted's catalogue endpoint. If Vinted blocks cross-site requests (CORS), this page cannot load listings on GitHub Pages alone. It never asks for your Vinted password and sends no data to us. Search text is sent only to Vinted when you test or search. Browser settings are saved locally. No scraping proxies or paid APIs are used.
